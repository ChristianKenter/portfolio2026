This week I focused on defining the idea behind MyOllama and establishing what I wanted the application to achieve.

The main goal is to create a backend application that allows users to generate short quiz videos by selecting a category. The application should automatically generate a question, create answer options, produce speech and combine the necessary media into a finished video.

I started by breaking the project into smaller components: user accounts, authentication, quiz generation, audio generation, media resources and video rendering.

This helped me understand how the different services would need to communicate. I also began thinking about the order of the workflow, from receiving a user's request to returning the completed MP4 file.

Next week I will focus on the technical architecture and the technologies needed to make the application work.
